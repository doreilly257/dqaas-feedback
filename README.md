# DQaaS feedback

Public place for feedback and bug reports about DQaaS (https://dqaas.io), the data quality, profiling and catalogue service. This repository holds issues only: there is no source code here.

- Open an issue: choose a template under Issues, New issue.
- Prefer email? Write to feedback@dqaas.io. That address is read in private.
- Security problem? Do not open an issue. Email security@dqaas.io (see https://dqaas.io/security/).

Issues here are public. Never post your data, credentials, access tokens, or personal details, and blur screenshots. Say which part you used (console, API, CLI, MCP, or the in-browser mode) and the steps that led to the problem.
